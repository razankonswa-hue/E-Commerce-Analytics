# 🛒 E-Commerce Analytics
## 📌 Project Overview

This project analyzes an e-commerce dataset to uncover key insights into sales performance, customer behavior, product performance, reviews, and user engagement.

The project follows a complete data analytics workflow, starting with data preparation and exploration in Excel, followed by SQL Server analysis, and ending with an interactive Power BI dashboard.

The main goal is to transform raw e-commerce data into meaningful business insights that can support data-driven decision-making.
## 🎯 Business Questions

The analysis focuses on answering the following questions:

- How do revenue and order volume change over time?
- Which products generate the highest revenue?
- What is the Average Order Value (AOV) and how does it change over time?
- What is the average number of orders per customer?
- Which products have high sales but low ratings?
- Is there a relationship between customer engagement and sales performance?
- How do product categories compare in terms of revenue and sales?
- What percentage of customers are one-time vs. repeat customers?
- Which products receive the most negative reviews?
- What insights can be derived from customer behavior and product performance?
## 🗂️ Dataset

## The dataset contains multiple interconnected tables representing different aspects of an e-commerce platform:

Tables
- Users — Customer information
- Products — Product details and categories
- Orders — Order information and transaction values
- Order Items — Products included in each order
- Reviews — Customer ratings and reviews
- Events — User interaction and engagement data

💡 Key Insights

The analysis was designed to identify actionable insights such as:

- Revenue and order trends over time
- Products contributing the most revenue
- Differences in customer purchasing behavior
- Products with strong sales but weaker customer ratings
- Categories with stronger sales performance
- Differences between repeat and one-time customers
- Products receiving a high number of negative reviews
- The relationship between user engagement and purchasing activity
## 💡 Recommendations

-  Focus on high-revenue products and optimize their availability.
-  Improve products with high sales but low ratings.
-  Encourage repeat purchases through personalized offers and loyalty programs.
-  Monitor negative reviews to identify areas for improvement.
-  Use customer engagement data to support targeted marketing.
